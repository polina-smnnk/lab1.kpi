# EduFlow — Платформа онлайн-освіти

## Доменна область
EduFlow — вебплатформа для управління онлайн-курсами, студентами та навчальними матеріалами.

### Основні сутності:
* **User** — користувачі системи (студенти та викладачі).
* **Course** — навчальні  курси.
* **Module** — тематичні модулі всередині  курсів.
